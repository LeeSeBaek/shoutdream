# 무료/오픈소스(또는 Freemium) API 100선

본 문서는 다양한 도메인(데이터, AI, 번역, 이미지, 날씨, 오디오, 뉴스, 텍스트, PDF, 결제, 위치, 이메일 등)의 개발에 유용한 무료/오픈소스(또는 Freemium) API 100개를 한곳에 모아 정리한 자료입니다. 각 항목은 이름, 공식 문서/홈페이지 링크, 요약 설명, 대표 용도를 포함하며 한국어로 일관되게 작성했습니다.

주의: 가격/정책은 변동될 수 있으니, 사용 전 반드시 공식 문서를 확인하세요.

## 분류 키
- 데이터/오픈데이터(OD)
- 인공지능/LLM/ML(AI)
- 번역/자연어(TRANS/NLP)
- 이미지/비전(IMG)
- 음성/오디오(AUDIO)
- 날씨/지구과학(WEATHER)
- 뉴스/콘텐츠(NEWS)
- 텍스트 도구/문서 처리(TEXT/PDF)
- 결제/상거래(PAY)
- 위치/지도/지오(LOCATION)
- 이메일/메시징(COMMS)
- 인증/보안(AUTH)
- 개발자 도구/운영(DEV)

1) Open-Meteo (WEATHER)
- 링크: https://open-meteo.com/
- 설명: 무료 오픈 날씨/기상 예측 API, 개인/상업적 사용에 제한이 적음.
- 대표 용도: 현재/예보 날씨, 풍속, 태양광/기상 데이터 시각화.

2) OpenWeather Free (WEATHER)
- 링크: https://openweathermap.org/api
- 설명: 전 세계 날씨 관측/예보/히스토리 데이터를 제공하는 대표적 서비스.
- 대표 용도: 현재 날씨, 단기/중기 예보, 대기오염 지수.

3) WeatherAPI.com (WEATHER)
- 링크: https://www.weatherapi.com/
- 설명: 날씨/천문/대기질 API, 무료 티어 제공.
- 대표 용도: 현재/과거/예보 날씨, 위치 기반 날씨 위젯.

4) Meteostat (WEATHER/OD)
- 링크: https://meteostat.net/
- 설명: 오픈 기상 관측/기후 데이터. REST/파이썬/라이브러리 제공.
- 대표 용도: 기상 관측 시계열 분석, 연구용 데이터 수집.

5) NASA Open APIs (OD)
- 링크: https://api.nasa.gov/
- 설명: 천문 사진(APOD), 화성 기상, 지구 관측 등 다양한 공개 데이터.
- 대표 용도: 우주/지구 과학 데이터 시각화, 교육/연구 콘텐츠 제작.

6) USGS Earthquake API (OD)
- 링크: https://earthquake.usgs.gov/fdsnws/event/1/
- 설명: 전 세계 지진 이벤트 피드. 포맷/필터링 지원.
- 대표 용도: 지진 모니터링 대시보드, 재난 알림.

7) OpenAQ (OD/WEATHER)
- 링크: https://docs.openaq.org/
- 설명: 전 세계 대기질 오픈 데이터.
- 대표 용도: PM2.5/PM10, NO2 등 공기질 분석/시각화.

8) World Air Quality (WAQI) (WEATHER)
- 링크: https://aqicn.org/api/
- 설명: 실시간 공기질 지수 AQI 제공(비상업/연구 무료, 상업 제한 확인).
- 대표 용도: 도시별 대기질 지도/알림.

9) OpenStreetMap Nominatim (LOCATION)
- 링크: https://nominatim.org/release-docs/develop/api/Overview/

- 대표 용도: 주소→좌표, 좌표→주소 변환.

10) Mapbox Geocoding (LOCATION)
- 링크: https://docs.mapbox.com/api/

- 대표 용도: 지도 표시, 경로 탐색, 장소 검색.

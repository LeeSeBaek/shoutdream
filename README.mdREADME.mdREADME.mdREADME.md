# 오픈소스 100선

최신 인기 오픈소스 및 개발자 필수 오픈소스 툴 100개를 선별해 정리했습니다. 아래 예시 표(10개)는 형식을 보여주기 위한 샘플이며, 동일한 형식으로 100개까지 채워 넣습니다.

## 선정 기준
- 활발한 유지보수와 별(Star) 수, 커뮤니티 활동성
- 실제 개발 워크플로우에 유용성(개발, 테스트, 배포, 관측, 협업 등)
- 다양한 언어/플랫폼을 포괄

## 사용 방법
- 표의 링크를 통해 깃허브(또는 공식 사이트)로 이동하여 설치 및 문서를 확인하세요.

## 예시(10개 샘플)

| 번호 | 프로젝트 | 카테고리 | 링크 | 한줄 설명 |
|---|---|---|---|---|
| 1 | React | 프론트엔드 UI 라이브러리 | https://github.com/facebook/react | 컴포넌트 기반의 선언적 UI 라이브러리 |
| 2 | Vue.js | 프론트엔드 프레임워크 | https://github.com/vuejs/core | 가볍고 배우기 쉬운 점진적 프레임워크 |
| 3 | Next.js | 풀스택 웹 프레임워크 | https://github.com/vercel/next.js | React 기반의 SSR/SSG, 라우팅, 빌드 통합 |
| 4 | Nuxt | 풀스택 웹 프레임워크 | https://github.com/nuxt/nuxt | Vue 기반 SSR/SSG 프레임워크 |
| 5 | Angular | 프론트엔드 프레임워크 | https://github.com/angular/angular | 대규모 애플리케이션에 적합한 견고한 구조 |
| 6 | Svelte | 프론트엔드 컴파일러 | https://github.com/sveltejs/svelte | 런타임 오버헤드를 줄이는 컴파일 중심 접근 |
| 7 | Tailwind CSS | CSS 유틸리티 프레임워크 | https://github.com/tailwindlabs/tailwindcss | 유틸리티 클래스 기반으로 빠른 스타일링 |
| 8 | Bootstrap | CSS 프레임워크 | https://github.com/twbs/bootstrap | 반응형 레이아웃과 컴포넌트 제공 |
| 9 | Material UI | React UI 컴포넌트 | https://github.com/mui/material-ui | 구글 머티리얼 디자인 구현 컴포넌트 |
| 10 | Vite | 프론트엔드 빌드 툴 | https://github.com/vitejs/vite | 초고속 개발 서버와 번들링 지원 |

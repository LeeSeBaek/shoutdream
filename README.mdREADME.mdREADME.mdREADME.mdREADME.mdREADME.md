# 오픈소스 100선
최신 인기 오픈소스 및 개발자 필수 오픈소스 툴 100개를 선별해 정리했습니다. 아래 표는 카테고리 다양성과 문장 일관성을 유지하여 구성되었습니다.

## 선정 기준
- 활발한 유지보수와 별(Star) 수, 커뮤니티 활동성
- 실제 개발 워크플로우에 유용성(개발, 테스트, 배포, 관측, 협업 등)
- 다양한 언어/플랫폼을 포괄

## 사용 방법
- 표의 링크를 통해 깃허브(또는 공식 사이트)로 이동하여 설치 및 문서를 확인하세요.
